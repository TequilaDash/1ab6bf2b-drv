# 10-25 第八波（本轮终点）：cmd5 入队函数内部

## 0x1BAE3DC（cmd 入队）内部结构
```
x19 = [session+0x20]（队列/WorkPool 对象）, x20 = session, w21 = cmd(5), x22/x23 = Configure 局部
0x1bae4c4: x2 = [session+0x60]；0x842eafc(0x2ba609c, [session+0x60], 0xa, 0,0,0) —— 日志/计数
0x1bae4ec: x0 = [x19+0xc8]          ← 队列对象 +0xc8（入队器子对象）
0x1bae504: PAC vtable 校验 → 调 [vtable+0xe8](x0, type_token=0x8acaa98|PAC, x2=session, x3=cmd, x4=x22, x5=x23)
  返回 x24 → 日志（fmt 0x28f3ac）→ 后续即最终返回
```
- **入队实现 = [session+0x20]+0xc8 对象的虚方法 +0xe8**；type token 0x8acaa98（OSMetaClass 风格 PAC 指针）→ 该子对象的类可由 0x8acaa98 附近 metacls 反查。
- x22/x23（入队 payload 的两个指针）= Configure 局部：x22 在 0x1a7b884 处 = Configure 的 x3 = **&in[0x22c]**；x23 = x4 = **&in[0x340]**（executor 0x1a7c710 块的 x3=x20 来源需最后一核）。
- ⇒ **命令 5 的 payload = Prepare 输入的两个子结构指针**（0x22c/0x340 起）——与 v47 的 LRB param 绝对偏移 0x264/0x26c/0x270/0x274/0x278 同属 0x22c-0x340 窗口！**入队 payload 就含 LRB 五元组区**。

## 收束结论（本会话终点状态）
- sel5 -1015 的完整因果链：Configure 深链 cmd5 入队（0x1BAE3DC）→ [vtable+0xe8] 入队实现 → WorkThread → WorkPool 簇 → 0x1b66980 创建+注册 cookie 条目 → 之后 sel5 查表可命中。
- 入队失败的根因在 [session+0x20]+0xc8 子对象状态或 payload 校验——**下一班第一刀：0x1BAE3DC 最终返回值来源（mov w0, x24 前后的转换）+ vtable+0xe8 实现函数定位**（从 [session+0x20] 的类 vtable 找 +0xe8 槽）。
- 上机信号：若入队成功，sel4 后 IOSurface ID 应跳变（新建 surface）——surf_make_id 前后对比即可零成本验证。
- v55 探针在设备；全部六日 journal 落盘（本文件为终波）。

## 第十波（真终点）：最内层门 0x1B80288 破译

```
0x1B80288([session+0x2d0]):
  count = [容器+0x1c]
  for i = 4 .. count+3:                      ★ 起始 i=4，数组基址容器+0x20
    entry = [容器 + i*8]
    ret = entry->vtable[+0x10](entry)         （PAC tag 0x82f3）
    ret != 0 → 日志（行号 0x147）→ 门失败
  全过 → return 0
```
- 空容器（count=0）直通——create 初始化的空池**不应**在此失败。
- ⇒ **MS patch 下的失败点在 0x1a77104 的 0x1b230 之后**（0x1B80288 成功后的剩余段，含 [session+0x30] 的使用——x21=[session+0x30] 在 0x1b80288 前已取，说明门后还有 0x30 相关检查）。
- **下一班开局 = show 0x1a77230 起的门内剩余段**（foff 口径），逐段对照 MS patch 状态找第一个非 0 返回。

## 第十二波：+0xc8 子对象构造点锁定

- **[X+0xc8] 子对象构造链**（全 foff）：调用点 **0x1b01608**（kalloc type 0xfffffff007bd5eb0 → memset 0x1b25d24 → **真构造 0x1b25d50**（tag 0x5b，7 参：x1=栈值,x2/x3,x4/x5=[X+0x70],x6=[X+0x80],x7=[X+0xa0]）→ 写回 [X+0xc8]）。
